# Terminal Commands

You have been introduced to a variety of terminal commands this week – fill out the table with an explanation for each command which says what it is used for.

You may find it useful to run these commands in the terminal of Codespace to remind yourself.

You should put your explanations between the \| \| characters.

You can complete this task on the worksheet pdf if you prefer.

|     Command                 |     Explanation    |
|-----------------------------|--------------------|
|     pwd                     | shows the current location of the terminal |
|     ls                      | shows the files in the current location |
|     cd directory_name       | takes you to the selected location |
|     cd ..                   | moves up one level to the parent directory |
|     cd -                    | takes typo back to the previous location |
|     mkdir directory_name    | creates a new folder with the name you give it |
|     touch filename          | creates a new empty file with the name you give it |
|     git status              |  shows the current state of your Git repository |
|     git add -A              | adds all the changes to the staging area |
|     git commit -m ""        | saves the staged changes |
|     git push                | sends your local commits to the remote repository |
|     git pull                | gets changes from the remote repository and brings it to your current repository |
